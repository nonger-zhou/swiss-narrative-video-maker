# Task 020: Fact Check Revision Bridge

## Goal

Make fact checking easier to turn into a careful script revision without automating factual judgment or rewriting the copy without the creator.

## Review Player Changes

The fact-check panel now includes an editable focus field. This is useful when a caption line splits a factual claim, such as one subtitle saying only the setup and the next subtitle containing the number. The creator can paste or type the complete claim before opening ChatGPT, Perplexity, or Google.

The player also shows fact-check results saved for the current scene. Each saved result can be carried into the script edit note, and the script edit intent is marked as:

- `fact_fix`
- `needs_source`

## Boundaries

This task does not decide whether a fact is true. It keeps the external, user-driven fact-check workflow and only makes the handoff into script editing easier.
